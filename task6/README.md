# Лабораторная №6 — «Змейка»

Игра «Змейка» на canvas 400×400 (сетка 20×20): управление стрелками, яблоко, счёт, конец игры и рестарт без перезагрузки. Игровой цикл — `requestAnimationFrame` с шагом по времени (150 мс), состояние хранится в объекте `state`.

Запуск: открыть `index.html` в браузере (двойной клик или Live Server).
