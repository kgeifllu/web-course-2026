# Task 2 — Адаптивная вёрстка. Лендинг «Бюро Необъяснимого»

Одностраничный лендинг-архив о загадочных явлениях (Бермудский треугольник, Бигфут, Лох-Несское чудовище, Зона 51, круги на полях, полтергейст). Адаптивная вёрстка с тремя контрольными точками (mobile / tablet / desktop) по подходу Mobile First. Крупная сетка страницы — на CSS Grid, компоненты (карточки, форма, меню) — на Flexbox. Все факты и фото — с реальными источниками (Wikipedia, Wikimedia Commons).

Как запустить: открыть index.html в браузере, либо посмотреть опубликованную версию по ссылке https://kgeifllu.github.io/web-course-2026/task2/

За основу композиции взят бесплатный макет Figma Community «Performance-Driven Gym» (тема и контент изменены самостоятельно).
