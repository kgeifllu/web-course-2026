# Task 3 — Основы JS и DOM: Todo-list

Интерактивный список задач на чистом JavaScript (без библиотек и фреймворков). Добавление, отметка выполнения, удаление, фильтрация по статусу (все / активные / завершённые), счётчики задач. Данные хранятся в массиве объектов в памяти, разметка задач генерируется через JS (createElement), обработчики событий подключены через addEventListener.

Как запустить: открыть index.html в браузере, либо посмотреть опубликованную версию по ссылке https://kgeifllu.github.io/web-course-2026/task3/
