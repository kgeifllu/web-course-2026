# Task 1 — Семантическая вёрстка. Страница-резюме

Одностраничное резюме системного аналитика, свёрстанное семантическими тегами HTML5 (header, nav, main, section, footer) с раскладкой блоков через Flexbox.

Как запустить: открыть index.html в браузере, либо посмотреть опубликованную версию по ссылке https://kgeifllu.github.io/web-course-2026/task1/
