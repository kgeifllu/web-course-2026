# Лабораторная №7 — «Лента постов»

Лента постов с JSONPlaceholder: загрузка порциями по 10 (`_start`/`_limit`, async/await, try/catch), бесконечный скролл через IntersectionObserver до 100 постов, поиск по заголовку среди загруженных постов с дебаунсом 300 мс и понятные сообщения об ошибках с кнопкой «Повторить».

Запуск: открыть `index.html` в браузере (нужен интернет; удобнее через Live Server).
